# Text Quest Reader

![Unity](https://img.shields.io/badge/engine-Unity-000000?logo=unity&logoColor=white)
![Language](https://img.shields.io/badge/language-C%23-blue)
![Format](https://img.shields.io/badge/data-JSON-orange)
![License](https://img.shields.io/badge/license-MIT-green)

Ридер текстовых квестов для запуска ветвящихся сюжетных сценариев, вдохновлённый механиками игры «Космические Рейнджеры».

Вместе с инструментом [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor) образует систему для создания и запуска собственных текстовых квестов.

В отличие от аналогов, не привязан к конкретной игре или платформе — квесты можно использовать в любых проектах.

Поддерживает:
- локации и переходы  
- параметры и формулы  
- изображения  
- звуки и музыку  
- локальные и удалённые квесты (через API)
- языковые настройки квестов

Квесты хранятся в JSON-формате, что позволяет:
- легко переносить их между проектами
- хранить отдельно от Unity-сцен
- использовать в собственных runtime-системах

## Local и Remote квесты

Ридер поддерживает два источника квестов:

- **Local** — квесты, расположенные в папке `StreamingAssets/Quests`
- **Remote** — квесты, загружаемые с сервера через API

Remote-квесты можно запускать без ручного копирования файлов.

Если сервер недоступен, вкладка **Remote** автоматически отключается.

---

Проект является open source и может использоваться:
- как готовый ридер текстовых квестов
- как Unity runtime
- как пример интеграции JSON-квестов в Unity
- как основа для создания собственного ридера с кастомным UI
- как база для изменения UI и логики под собственные проекты

## Быстрый старт

### Запуск из Unity

1. Откройте проект в Unity  
2. Откройте сцену:  
   `Assets/_Scenes/MainScene.unity`  
3. Нажмите **Play**

---

### Проверка работы

После запуска:

- выберите квест (например, **Asteroid Station**)  
- нажмите **Start Quest**

Если всё корректно — квест запустится.

## Добавление квестов

Можно двумя способами:

### 1. Через папку

Поместите квест в:

`Assets/StreamingAssets/Quests/`

---

### 2. Через интерфейс

- **Add Quests** — открывает папку квестов  
- **Refresh** — обновляет список  

<img src="docs/add_quests_2.webp" width="400">

Позволяет добавлять квесты без перезапуска приложения.

---

## Важно

Имя квеста в `quest.json`:

```json
"questName": "YourQuest"
```

должно совпадать с названием папки.

---

## Структура квеста

Каждый квест — отдельная папка:

`Assets/StreamingAssets/Quests/YourQuest/`

### Содержимое:

- `quest.json` — логика и данные (обязательно)
- `Images/` — изображения (опционально)
- `Sounds/` — звуки (опционально)
- `Musics/` — музыка (опционально)

<img src="docs/quest_structure.webp" width="280">

Структура создаётся автоматически в [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor)  
Создавать вручную не нужно.

---

## Создание квестов

Используется отдельный инструмент:  
👉 [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor)

Позволяет:
- визуально создавать локации  
- настраивать параметры  
- задавать переходы  
- экспортировать готовый квест
- публиковать квесты на сервер
- обновлять remote-квесты

---

## Remote квесты (API)

Ридер поддерживает загрузку квестов с сервера.

### Возможности

- просмотр списка квестов  
- загрузка без копирования файлов  
- запуск удалённых квестов
- автоматическое отображение remote-квестов в списке
