# Text Quest Reader

![Unity](https://img.shields.io/badge/engine-Unity-000000?logo=unity&logoColor=white)
![Language](https://img.shields.io/badge/language-C%23-blue)
![Format](https://img.shields.io/badge/data-JSON-orange)
![License](https://img.shields.io/badge/license-MIT-green)

Рідер текстових квестів для запуску розгалужених сюжетних сценаріїв, натхненний механіками гри «Космічні Рейнджери».

Разом з інструментом [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor) утворює систему для створення та запуску власних текстових квестів.

На відміну від аналогів, не прив’язаний до конкретної гри чи платформи — квести можна використовувати в будь-яких проєктах.

Підтримує:
- локації та переходи  
- параметри та формули  
- зображення  
- звуки та музику  
- локальні та віддалені квести (через API)
- мовні налаштування квестів

Квести зберігаються у JSON-форматі, що дозволяє:
- легко переносити їх між проєктами
- зберігати окремо від Unity-сцен
- використовувати у власних runtime-системах

## Local / Remote квести

Рідер підтримує два джерела квестів:

- **Local** — квести, розташовані у папці `StreamingAssets/Quests`
- **Remote** — квести, що завантажуються із сервера через API

Remote-квести можна запускати без ручного копіювання файлів.

Якщо сервер недоступний, вкладка **Remote** автоматично вимикається.

---

Проєкт є open source і може використовуватися:
- як готовий рідер текстових квестів
- як Unity runtime
- як приклад інтеграції JSON-квестів у Unity
- як основа для створення власного рідера з кастомним UI
- як база для зміни UI та логіки під власні проєкти

## Швидкий старт

### Запуск із Unity

1. Відкрийте проєкт у Unity  
2. Відкрийте сцену:  
   `Assets/_Scenes/MainScene.unity`  
3. Натисніть **Play**

---

### Перевірка роботи

Після запуску:

- виберіть квест (наприклад, **Asteroid Station**)  
- натисніть **Start Quest**

Якщо все коректно — квест запуститься.

## Попередження безпеки macOS

Якщо macOS блокує застосунок із повідомленням:

> «Застосунок не може бути відкритий, оскільки не вдалося перевірити його розробника»

Зробіть наступне:

1. Відкрийте:
   `System Settings → Privacy & Security`

2. Прокрутіть вниз до розділу безпеки

3. Натисніть:
   **Open Anyway / Усе одно відкрити**

4. Підтвердьте запуск застосунку

Після першого запуску застосунок відкриватиметься нормально.

## Додавання квестів

Рідер підтримує:
- локальні квести
- віддалені квести (Remote/API)

### 1. Локальні квести через папку в Unity-проєкті

Помістіть папку квесту в:

`Assets/StreamingAssets/Quests/`


### 2. Локальні квести через інтерфейс застосунку

- **Add Quests** — відкриває папку квестів  
- **Refresh** — оновлює список  

<img src="docs/add_quests_2.webp" width="400">

Дозволяє додавати локальні квести без перезапуску застосунку.


### 3. Remote-квести

Віддалені квести публікуються через [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor).

Після публікації квест автоматично стає доступним у розділі **Remote** всередині **Text Quest Reader**.

## Важливо для локальних квестів

Ім’я квесту в `quest.json`:

```json
"questName": "YourQuest"
```

має збігатися з назвою папки.

---

## Структура квесту

Кожен квест — окрема папка:

`Assets/StreamingAssets/Quests/YourQuest/`

### Вміст:

- `quest.json` — логіка та дані (обов’язково)
- `Images/` — зображення (опціонально)
- `Sounds/` — звуки (опціонально)
- `Musics/` — музика (опціонально)

<img src="docs/quest_structure.webp" width="280">

Структура створюється автоматично у [**Text Quest Editor**](https://github.com/albruevich/Text-Quest-Editor)  
Створювати вручну не потрібно.
