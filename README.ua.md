# Text Quest Reader

![Unity](https://img.shields.io/badge/engine-Unity-000000?logo=unity&logoColor=white)
![Language](https://img.shields.io/badge/language-C%23-blue)
![Format](https://img.shields.io/badge/data-JSON-orange)
![License](https://img.shields.io/badge/license-MIT-green)

Рідер текстових квестів для запуску розгалужених сюжетних сценаріїв, натхненний механіками гри «Космічні Рейнджери».

Разом з [Text Quest Editor](https://github.com/albruevich/Text-Quest-Editor) утворює систему для створення та запуску власних текстових квестів.

На відміну від аналогів, не прив’язаний до конкретної гри чи платформи — квести можна використовувати у будь-яких проєктах.

Підтримує:
- локації та переходи
- параметри та формули
- зображення
- звуки та музику
- локальні та віддалені квести (через API)

Проєкт є open source і може використовуватись:
- як готовий рідер текстових квестів
- як приклад інтеграції JSON-квестів в Unity
- як основа для створення власного рідера з кастомним UI

## Швидкий старт

### Запуск з Unity

1. Відкрийте проєкт у Unity
2. Відкрийте сцену:
   `Assets/_Scenes/MainScene.unity`
3. Натисніть **Play**

---

### Перевірка роботи

Після запуску:

- виберіть квест (наприклад, **Asteroid Station**)
- натисніть **Почати вибраний квест**

Якщо все працює коректно — квест запуститься.

## Додавання квестів

Є два способи:

### 1. Через папку

Помістіть квест у:

Assets/StreamingAssets/Quests/

---

### 2. Через інтерфейс

- **Додати Квести** — відкриває папку квестів
- **Оновити** — оновлює список

<img src="docs/add_quests.webp" width="400">

Дозволяє додавати квести без перезапуску застосунку.

---

## Важливо

Ім’я квесту в `quest.json`:

"questName": "YourQuest"

має збігатися з назвою папки.

---

## Структура квесту

Кожен квест — окрема папка:

Assets/StreamingAssets/Quests/YourQuest/

### Вміст:

- `quest.json` — логіка та дані (обов’язково)
- `Images/` — зображення (необов’язково)
- `Sounds/` — звуки (необов’язково)
- `Musics/` — музика (необов’язково)

<img src="docs/quest_structure.webp" width="280">

Структура створюється автоматично у **Text Quest Editor**.
Створювати вручну не потрібно.

## Створення квестів

Використовується окремий інструмент:
👉 [Text Quest Editor](https://github.com/albruevich/Text-Quest-Editor)

Дозволяє:
- візуально створювати локації
- налаштовувати параметри
- задавати переходи
- експортувати готовий квест

## Remote квести (API)

Рідер підтримує завантаження квестів із сервера.

### Можливості

- перегляд списку квестів
- завантаження без копіювання файлів вручну
- запуск віддалених квестів
